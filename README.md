# Coffee Shop Sales Dashboard (Excel)
## Project Overview

This project presents an interactive Coffee Shop Sales Dashboard developed using Microsoft Excel to analyze sales performance, customer behavior, product demand, and store operations.

The dashboard transforms raw transactional data into meaningful business insights using advanced data analysis, Pivot Tables, charts, and interactive visualizations to support data-driven decision-making.

# Objectives
The main objectives of this project are:

• Analyze overall sales performance

• Track customer footfall and purchasing behavior

• Identify peak business hours and demand trends

• Evaluate product category performance

• Compare store-wise sales and customer engagement

• Build an interactive and professional Excel dashboard

## Dashboard Features
### KPI Metrics

The dashboard includes important business KPIs such as:

• Total Sales

• Total Footfall

• Average Bill per Person

• Average Orders per Person

### Sales & Customer Analysis
• Hourly order analysis to identify peak customer activity hours

• Weekday-wise order trends to analyze customer engagement patterns

• Order size distribution analysis to understand purchasing behavior

### Product Performance Analysis
Category-wise sales distribution across products including:

• Coffee

• Bakery

• Tea

• Chocolate

The dashboard also identifies top-performing products based on revenue contribution.

### Store Performance Analysis
• Comparison of sales across multiple store locations

• Footfall analysis by store

• Store-wise performance insights

### Interactive Dashboard Features
Interactive slicers and filters implemented for:

• Product Category

• Store Location

• Time-based Analysis

These filters improve dashboard interactivity and user experience.
